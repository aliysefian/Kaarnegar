## Kaarnegar 1.1.0

### What's new

- **Cloud sync.** Choose a folder inside Dropbox, Google Drive, or any synced directory in **Settings → Cloud sync**, and Kaarnegar keeps your organizations, projects, and time entries in step across computers. Use the same folder on every computer.
- Each computer writes its own file in the folder, so cloud clients never create conflicted copies. Deletions carry over to the other computers.
- A running timer stays on the computer it is running on.
- If two computers edit the same entry, the most recent sync wins.

### Upgrading

Quit the previous version from the system tray before installing or opening this release. Your existing work history and preferences remain on your computer. Sync is off until you choose a folder.

### Downloads

- **Windows installer:** `Kaarnegar-Setup-1.1.0.exe`
- **Windows portable:** `Kaarnegar-1.1.0.exe`
- **Linux AppImage:** `Kaarnegar-1.1.0-x86_64.AppImage`
- **Linux Debian package:** `Kaarnegar-1.1.0-amd64.deb`
- **Checksums:** `SHA256SUMS.txt`

For the AppImage, run `chmod +x Kaarnegar-1.1.0-x86_64.AppImage` before opening it. The AppImage runtime requires FUSE 2; use the Debian package if your system does not provide it. Install the Debian package with `sudo apt install ./Kaarnegar-1.1.0-amd64.deb`.
